# Журнал настройки пунктуации

Стенд: `npm run eval:punct -- --set dev` (настройка), `--set test` только для итогового отчёта. Колонки: sure — recall / precision / лишних на чистых (на 1000 предложений); all — то же для sure + check. Порог отката: precision sure на dev ниже 88 % или лишних на чистых (sure) выше 8/1000.

Базовая линия снята на `73bd6bd` (движок и базы те же, что в `befb6f2`): dev 3 942 предложений, 7 184 правок в зачёте, 19 894 чистых.
