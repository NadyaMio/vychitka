Первая версия «Вычитки» — корректора русского текста без ИИ для Windows и macOS.

- Вставка текста из буфера с форматированием или открытие DOCX, RTF, ODT, TXT, MD, PDF.
- Корректура: орфография, пунктуация, грамматика, типографика — правки списком с объяснением и параграфом Правил 1956 г.
- Правка текста прямо в окне с автоматической перепроверкой.
- До / после, сохранение DOCX с режимом правок Word, отчёт корректора в PDF.
- Литературная правка, сверка версий, «Мой словарь», справочник правил.
- Автообновление приложения и отдельное обновление словарных баз с GitHub.

Файлы: Windows — Vychitka-Setup-*.exe; macOS Apple Silicon — *-mac-arm64.dmg; macOS Intel — *-mac-x64.dmg. Про первый запуск неподписанного приложения — в README.
