# Вычитка — корректор русского текста без ИИ

Десктоп-приложение для Windows и macOS. Вставляете текст любой длины (или открываете файл) — приложение находит опечатки, пропущенные запятые, ошибки согласования и типографики, по запросу проводит литературную правку и сверяет версии текста. Ничего не исправляет само: каждую правку можно посмотреть, отклонить или принять — все разом или выборочно.

Работает только на словарях и правилах, без нейросетей и без интернета: один и тот же текст всегда даёт один и тот же результат, а у каждой правки есть объяснение и ссылка на параграф официальных «Правил русской орфографии и пунктуации».

## Скачать

Последняя версия — на странице [Releases](https://github.com/NadyaMio/vychitka/releases/latest):

| Система | Файл |
|---|---|
| Windows 10/11 | `Vychitka-Setup-X.Y.Z.exe` |
| macOS на Apple Silicon (M1–M4) | `Vychitka-X.Y.Z-mac-arm64.dmg` |
| macOS на Intel | `Vychitka-X.Y.Z-mac-x64.dmg` |

**Первый запуск.** Приложение пока не подписано платным сертификатом, поэтому система предупредит:
- **Windows:** «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
- **macOS:** перетащите «Вычитку» в «Программы», затем правой кнопкой по значку → «Открыть» → «Открыть». Если macOS пишет, что приложение повреждено: в Терминале `xattr -dr com.apple.quarantine /Applications/Vychitka.app`.

## Что умеет

- **Вставка из буфера** (⌘V / Ctrl+V) с сохранением жирного, курсива и ссылок — из Word, Google Docs, писем, браузера. Или файл: DOCX, RTF, ODT, TXT, MD, PDF с текстовым слоем.
- **Корректура:** орфография (словарь OpenCorpora + поиск похожих слов с учётом падежа), пунктуация (союзы, вводные слова, обороты, однородные члены), грамматика (в течение, по приезде, согласно чему), типографика («ёлочки», длинное тире, разряды чисел, неразрывные пробелы). Спорные случаи помечаются «Проверьте».
- **Правки списком:** у каждой — правило, источник, параграф Правил 1956 г. (открывается полным текстом с примерами). Принять / отклонить / пропускать везде, выбрать часть и применить разом.
- **Правка прямо в окне:** текст редактируется как в обычном редакторе, абзац перепроверяется сам, ставшие ненужными правки снимаются.
- **До / после** и сохранение: копия DOCX **с режимом правок Word** (рецензирование, автор «Вычитка»), копия начисто или перезапись исходника с резервной копией; **отчёт корректора** в PDF.
- **Литературная правка:** канцелярит и штампы, отглагольные существительные, повторы, длинные предложения, пассив, слова-усилители; оценка ясности текста; варианты замены на выбор.
- **Сверка версий:** исправленный текст ↔ вёрстка (в том числе PDF): потерянные абзацы, невнесённые правки, слетевшие пробелы, изменённые слова; отчёт о сверке.
- **Словари и базы:** «Мой словарь» (имена, термины), общий словарь редакции в облачной папке, справочник правил с поиском.
- **Профили проверки:** редакционная норма, художественный текст, деловой документ, только опечатки — и свои.

## Обновления

- **Приложение** само проверяет новую версию в релизах этого репозитория. На Windows обновление скачивается и ставится после перезапуска; на macOS приложение скачивает новый образ и заменяет себя (если папка «Программы» недоступна для записи — открывает образ, чтобы перетащить вручную). Проверить вручную: меню «Вычитка» (macOS) или «Файл» (Windows) → «Проверить обновления приложения…».
- **Базы словарей и правил** обновляются отдельно от приложения: «Словари и базы» → «Проверить обновления» (и тихая проверка раз в неделю). Скачиваются только изменившиеся файлы, каждый сверяется по SHA-256; если что-то пошло не так, приложение продолжает работать на прежних базах.

Защищённые словари (Ожегов, Лопатин, Зализняк), Грамота.ру и Национальный корпус русского языка не копируются: Грамота открывается ссылкой из карточки слова, остальное можно подключить только по лицензии правообладателей. Подробно — [bases/LICENSES.md](bases/LICENSES.md).

## Для разработчиков

```bash
npm install
npm start            # запустить приложение
npm test             # движок и модули (node:test)
npm run test:e2e     # сквозной тест интерфейса: Electron + Playwright, скриншоты в test/e2e/out
npm run dist:mac     # dmg (arm64 + x64) в release/
```

Устройство: `src/main` — окно, файлы, сохранение, обновления; `src/engine` — движок проверки (работает в отдельном потоке); `src/renderer` — интерфейс по макетам из Figma; `bases/` — обновляемые данные. Как добавить правило — [docs/ENGINE.md](docs/ENGINE.md).

**Релиз приложения:** поднять `version` в `package.json`, закоммитить, `git tag vX.Y.Z && git push --tags`. GitHub Actions прогонит тесты на macOS и Windows, соберёт установщики и опубликует релиз.

**Релиз баз:** изменить файлы в `bases/`, затем `npm run bases:manifest -- 2026.11.1`, закоммитить в `main`, `git tag bases-2026.11.1 && git push origin main --tags`. Приложения увидят новую версию баз по `bases/manifest.json`.
